# 每日整理 Prompt

这份 prompt 只负责“单次执行”。

长期规则、目录约束、frontmatter 规范、允许与禁止事项，统一以 [LLM维护手册.md](../LLM维护手册.md) 为准。

```text
你现在要执行一次“每日整理”。

在开始前，先读取并遵循：
- LLM维护手册.md

先明确：目标日（默认用户当前时区的当天）。日期不明确且无法从当前请求推断时，再询问。
输出位置：日志/YYYY/YYYY-MM-DD.md；有同范围文件时优先更新。

执行约束：
- 只使用明确属于本范围的素材；文件修改时间不能代替事件日期。
- 检查已有整理结果，只补增量，避免重复追加。
- 缺失记录如实注明，不能补造经历、成果或个人判断。
- 保留来源链接，区分用户决定与 AI 建议。
- 数量以真实材料为准，不为满足 3 到 5 个点而编造。
- 不默认创建定时任务、提交或推送；按用户明确授权执行。
- 收尾检查 YAML 属性、链接和 Git 差异，说明未完成的核验。

本次输入范围：
- 收集/Inbox.md
- 收集目录下今天新增的原始输入
- 今日日志：日志/YYYY/YYYY-MM-DD.md
- 如果今日日志引用了已有笔记，可以一并读取相关的感悟/知识/展望文件

本次任务目标：
1. 保留原始输入，不删除原始记录；
2. 把今天新增内容整理进更稳定的位置；
3. 优先更新已有笔记，只有在确实是新主题时才新建文件；
4. 输出一次清晰、克制、可复核的整理结果。

请按下面步骤执行：
1. 概括今天原始输入里最重要的 3 到 5 个点；
2. 更新今日日志；
3. 把适合长期保留的个人判断整理到 `感悟/`；
4. 把适合长期执行的目标或行动整理到 `展望/`；
5. 如果今天有明确的新知识点，再整理到 `知识/`；
6. 列出仍然需要我确认的内容。

最后输出：
- 你更新了哪些文件
- 你新建了哪些文件
- 哪些内容还需要我确认
```

## 使用方式

AI 能访问本仓库时，直接指定本提示词和日期范围，由 AI 读取以下文件；不能访问时再提供这些材料：

- `提示词/每日整理Prompt.md`
- `LLM维护手册.md`
- `收集/Inbox.md`
- 当天新建的原始输入
- 当天日志
- 可能会被更新的目标页或感悟页
